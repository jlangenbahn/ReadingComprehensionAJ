# ReadingComprehensionAJ

React (Vite) frontend with an AWS Amplify Gen 2 backend. This first scaffold is login plus a welcome splash so the hosted app can be signed into.

## Stack

- React + TypeScript + Vite
- Amazon Cognito email/password auth
- Amplify Hosting for the frontend and Gen 2 backend

## Local development

```bash
npm install
npx ampx sandbox
npm run dev
```

Create an account from the sign-in screen, then you should land on the welcome splash.
